### BrandsCard — Plataforma de Cartão Virtual (BaaS)

<img src="https://img.shields.io/badge/status-em%20produ%C3%A7%C3%A3o-2563EB?style=for-the-badge&labelColor=0A2540" alt="Em Produção" />
<img src="https://img.shields.io/badge/tipo-projeto%20corporativo%20%2F%20privado-1E3A5F?style=for-the-badge&labelColor=0A2540" alt="Projeto Privado" />
</div>

<br/>

API REST para gestão de transações por cartão virtual (BaaS — banking as a service), atendendo tanto usuários finais quanto estabelecimentos. O ecossistema inclui backoffice administrativo, aplicativo mobile para os clientes e um backend serverless rodando na AWS, com orquestração de faturamento e liquidação de empréstimos via filas e jobs agendados.
